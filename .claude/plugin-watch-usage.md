# watch 플러그인 (claude-video) 활용 가이드

`/watch <URL 또는 로컬 파일 경로>` — yt-dlp로 다운로드, ffmpeg로 프레임 추출, 자막/Whisper로 대본 추출 후 영상 내용에 대해 질문 가능.

## 이 프로젝트(GeometryDefender)에서 쓸 만한 상황

### 1. 버그 재현 영상 분석
플레이 중 이상한 현상을 화면 녹화해서 넘기면, 프레임 단위로 뭐가 잘못됐는지 짚어낼 수 있음.
- 예: "타자기 텍스트가 씹혀서 나옴" → 녹화 영상 `/watch` → 몇 프레임째부터 이상한지, 어떤 효과 태그 구간에서 깨지는지 확인 → `TextAnimationPlayer`/`TextAnimatorUtil` 코드와 대조
- 예: 토스트 스태킹이 겹쳐 보이는 문제, 몬스터 웨이포인트 이동이 튀는 문제 등 — 말로 설명하기 애매한 시각적 버그에 특히 유용

### 2. 이펙트/연출 레퍼런스 스카우팅
Text Animator, DOTween 관련 효과를 유튜브 쇼케이스 영상으로 보고 "이런 느낌으로 해줘" 할 때, 영상을 직접 보여주면 어떤 태그 조합(`<wave>`, `{fade}` 등)이나 TweenEffectPlayer 시퀀스로 재현할지 바로 제안 가능.

### 3. 경쟁작/유사 장르 분석
타워디펜스 장르 다른 게임의 웨이브 진행, 보스 등장 연출, 토스트/알림 UI 패턴을 담은 플레이 영상이나 devlog를 보고 WaveTable 밸런싱이나 UI 설계에 참고.

### 4. Unity 튜토리얼 소화
ECS/DOTS(EntityQuery, MonsterManager 구조와 연관), Text Animator, Addressables 등 프로젝트에서 쓰는 기술 튜토리얼 영상을 보여주면 핵심 스텝만 요약하거나, 지금 코드와 뭐가 다른지 비교 가능.

### 5. 에셋 구매 전 프리뷰 검토
에셋스토어 프리뷰 영상을 보고 실제로 프로젝트에 도입할 가치가 있는지, 어떤 컴포넌트 구조일지 미리 가늠.

## 사용 팁
- 로컬 녹화 파일이면 경로만 넘기면 됨 (`/watch D:\경로\bug.mp4`) — 업로드 없이 바로 분석
- 유튜브 등 URL도 가능 (yt-dlp가 다운로드) — 자막 있으면 자막 우선, 없으면 Whisper로 대본 추출
- 버그 재현 영상은 문제 구간만 짧게 잘라서 넘기는 게 프레임 추출/분석 정확도에 유리Uni
- 영상 분석 후 실제 코드 수정까지 이어가려면, 이 세션(또는 이어지는 대화)에서 관련 클래스명을 같이 언급해주면 바로 연결해서 확인 가능
