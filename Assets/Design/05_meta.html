메타 진행 시스템

카드가 한 런의 다양성을 만든다면, 메타는 며칠~수 주에 걸친 장기적 성장을 만든다. 죽어도 무언가 남는다는 안전망, 다음 런이 조금 더 강해진다는 약속이 모바일 캐주얼 리텐션의 핵심이다.

메타 자원: Geometry Shards

런이 끝나면 점수와 처치 수에 비례해 Shards를 획득한다. Shards는 런 사이에 영구 보존되며, 영구 업그레이드와 카드풀 확장에 사용된다.

Shards 정산 공식

shardsEarned = floor(survivalSec / 10) + floor(killCount / 50) + bossKills × 10

예시:
  5분 생존, 200킬, 보스 1처치
  → 30 + 4 + 10 = 44 Shards

  10분 생존, 800킬, 보스 2처치
  → 60 + 16 + 20 = 96 Shards

  15분 생존, 1500킬, 보스 3처치
  → 90 + 30 + 30 = 150 Shards

영구 업그레이드 트리

Shards로 해금하는 영구 업그레이드. 한 번 해금하면 이후 모든 런에 자동 적용된다. 트리 구조로 노드 간 의존성이 있다.

구현 노트 · UIMetaTree 화면

실제 화면은 아래 SVG처럼 4줄기를 한 화면에 동시에 그리지 않는다. 상단에 줄기 탭(STARTING POWER / CARD POOL / ECONOMY / UTILITY)을 두고, 탭을 전환하면 해당 줄기의 노드만 스크롤 목록에 표시된다. 각 노드는 토글형 버튼으로 표현되며 잠김(비용 표시, 선행 조건 충족 시에만 클릭 가능) → 해금(체크 표시) 상태로 전환된다. 해금은 영구적이라 한 번 켜진 토글은 다시 꺼지지 않고 고정(재클릭 불가)된다 — 일반적인 On/Off 토글과 달리 단방향이다. 구현: Assets/Resources/Prefabs/UI/UIMetaTree.prefab, Assets/Scripts/UI/UIMetaTree.cs.

점수 / 로컬 리더보드

각 런의 점수를 로컬에 기록. 최고 점수 + 최근 10개 런 기록 표시.

score = killCount × 10
      + bossKills × 500
      + survivalSec × 5
      + (cardsObtained² × 20)   // 빌드 깊이 보상

세이브 시스템

메타 진행도는 로컬에 영구 저장. JSON 파일 직렬화로 구현 (Application.persistentDataPath). PlayerPrefs는 사용하지 않음 (Android 강제 종료 시 손실 위험). 

// SaveData.cs
[Serializable]
public class SaveData
{
    public int Version;                       // 마이그레이션 대응
    public int Shards;
    public List<int> UnlockedMetaNodes;       // 해금된 M-XXX ID
    public int BestScore;
    public List<RunRecord> RecentRuns;        // 최근 10개
    public DateTime LastPlayedAt;
}

[Serializable]
public class RunRecord
{
    public int Score;
    public int KillCount;
    public int BossKills;
    public float SurvivalSeconds;
    public int CardsObtained;
    public DateTime PlayedAt;
}
세이브 정책
  • 저장 트리거: 런 종료, 메타 노드 해금, 앱 백그라운드 전환
  • 저장 경로: Application.persistentDataPath/save.json
  • 백업: 직전 세이브를 save.json.bak로 보존
  • 버전 필드 포함: 향후 마이그레이션 대응
