Game Design Document · v1.0

Geometry Defender

사방에서 몰려드는 도형들을 막아내는 미니멀 로그라이트 타워 디펜스. 하나의 중앙 타워, 무한 웨이브, 카드 드래프트, 영구 메타 성장 — Vampire Survivors의 떼몰림과 Rogue Tower의 빌드 다양성을 모바일 세로 화면에 압축했다.

한 줄 컨셉

도형이 도형을 막는다. 화면 중앙에 있는 단 하나의 타워가 사방에서 수렴해오는 기하학적 적들을 자동 사격으로 막아내고, 플레이어는 웨이브 클리어마다 등장하는 3장의 카드 중 하나를 선택해 매 런마다 다른 빌드를 완성한다. 죽으면 처음부터. 다만 영구적으로 누적되는 메타 진행도가 다음 런을 조금씩 강하게 만든다.

핵심 의사결정

Genre
로그라이트 타워 디펜스 (서바이버형 떼몰림 구조)
View
2D 탑다운, 고정 카메라
Platform
Mobile-first, 세로 화면 (9:19.5 ~ 9:21 대응)
Art Style
프리미티브 도형 + 단색 + 네온 글로우
Session
1런 10~15분 / 무한 웨이브 / 점수 기록
Progression
인-런 카드 드래프트 (휘발) + 메타 영구 해금
Tech Spike
ECS Hybrid — 적 시뮬레이션만 DOTS/Job/Burst, 그 외 MonoBehaviour
Engine
Unity 6 LTS
Dev Cycle
MVP 5일 (1런 코어) + 추가 2일 (메타 시스템)
