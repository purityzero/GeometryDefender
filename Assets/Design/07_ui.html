피드백 / 모션 규칙

탭 피드백

모든 탭 가능한 UI는 누르는 순간 0.95 스케일로 줄어들고 떼면 원복. 모바일 터치 피드백 필수.

진동 (Haptic)

카드 선택 Light · 레벨업 Medium · 보스 처치 Heavy · 사망 Strong. 설정에서 OFF 가능.

레벨업 전환

XP 게이지 차는 순간 시안 플래시(0.3초) → 일시정지 → 카드 UI 슬라이드 업.

데미지 텍스트

피격 시 작은 숫자, 0.5초 페이드아웃. 치명타는 1.5배 크기 + 노란색. 초당 10건 throttle.

접근성 / QoL

  • 왼손/오른손 모드 — 일시정지 버튼 위치 좌/우 반전
  • 색맹 모드 — 적 컬러를 도형 보조 표시로 강조 (v1.1)
  • 줌 — 핀치로 화면 20%까지 줌인 (소형 디바이스)
  • FPS 옵션 — 30 / 60 / Adaptive
