전투 시스템

Geometry Defender의 전투는 중앙 1타워의 자동 사격을 축으로 한다. 플레이어는 사격에 직접 개입하지 않고, 카드 선택을 통해 타워의 행동 양상을 결정한다. 모든 수치는 데이터 드리븐으로 분리되어 있어 빌드 다양성과 밸런싱이 양립한다.

중앙 타워

타워는 게임에서 유일한 아군 오브젝트이며, 화면 중앙에 고정된다. 이동·회전·배치 변경 모두 불가능. 오직 카드로만 성장한다.

타워 HP 시각 표현

타워의 HP는 별도 게이지 UI 없이, 육각형의 글로우 강도와 컬러 변화로 표현한다. HP가 낮을수록 글로우가 약해지고, 30% 이하에서는 적색 펄스가 점멸한다.

무기 시스템 (2026-07-27 추가)

중앙 타워 외에 WEAPON 카테고리 카드(04 Card System 참고)로 독립 쿨다운/타겟팅을 갖는 추가 무기 슬롯을 최대 5개까지 해금할 수 있다. 추가 무기는 전부 항상 발사되고(쿨다운 각자 독립), 데미지%/치명타%/공속% 같은 전역 카드 효과는 모든 무기에 공통 적용되지만, 기본 무기(중앙 타워)의 타겟팅 카드나 Double Shot은 추가 무기에는 영향을 주지 않는다.

레이저 빔 (Laser)

Laser는 투사체를 발사하지 않는 유일한 무기다 — 쿨다운(5초)이 끝나면 2초간(업그레이드 카드 #308로 최대 3.5초까지 연장) 90도/초로 계속 회전하며, 0.2초마다 부채꼴(반각 8도) 범위 안의 모든 적에게 동시에 피해를 준 뒤 사라지고 다시 쿨다운에 들어간다. 사거리는 다른 무기와 달리 제한이 없다(맵 전체 커버). 시각적으로는 흰색 코어 라인 + 무기 고유색(#44FF33) 외곽 글로우 2겹 구조로, "얇고 밝은 중심 + 은은하게 번지는 색"이 레이저 빔의 느낌을 낸다.

사격 시스템

타겟팅 우선순위

타워는 매 공격 쿨다운마다 사거리 내 적 중 한 마리를 선택해 발사한다. 기본 타겟팅은 Closest 고정이다. 타겟팅을 바꾸는 카드(구 Card-306/307, Target Strongest/Fastest)는 기획 검토로 카드 목록에서 제외되었다.

전략선택 기준해금 조건
Closest타워에서 거리가 가장 짧은 적기본
Strongest현재 HP가 가장 높은 적미사용 (카드 제거됨)
Weakest현재 HP가 가장 낮은 적카드 해금 (v1.1)

Random사거리 내 무작위디버프 카드 효과
DESIGN PATTERN

타겟팅 전략은 Strategy 패턴(ITargetingStrategy)으로 구현. 카드는 타워의 strategy 참조를 갈아끼우는 방식. 런타임에 전략을 바꿔도 다른 코드를 건드리지 않는다.

사거리 시각화

사거리는 평시에는 표시되지 않는다. 카드 선택 직후 1.5초간 사거리 원이 시안 점선으로 페이드 인/아웃 (변경 사항을 시각적으로 알림).

데미지 모델

최종 데미지는 다음 수식으로 계산된다.

최종 데미지 = (BaseDamage × DamageMul) × CritMul × (1 + ElementBonus)

  BaseDamage   : 타워 기본 데미지 (=10)
  DamageMul    : 카드 누적 데미지 배율 (가산식: 1.0 + 0.2 + 0.3 = 1.5)
  CritMul      : 치명타 시 ×CritMultiplier, 아니면 ×1.0
  ElementBonus : 속성 카드의 적 타입 보너스 (없으면 0)

예시: 카드 3장 누적 (+20%, +20%, +40%), 치명타 발동
  최종 = (10 × 1.8) × 2.0 × 1.0 = 36
스택 규칙: 가산 only

같은 카드를 여러 번 뽑으면 효과는 가산된다. 예: "데미지 +20%" 카드 3장 → +60% (×1.6), 곱셈 ×1.728이 아님. 곱연산은 빌드가 빠르게 폭주하므로 의도적으로 회피.

치명타 시스템

치명타는 매 발사마다 독립적으로 굴린다. 치명타 시 데미지 숫자가 더 크게 표시되며, 적 사망 시 폭발 이펙트가 추가된다.

  • 치명타율 상한: 100% (그 이상은 무의미하므로 카드 안 나옴)
  • 치명타 배율 상한: ×5.0
  • 치명타 발생 시 효과음 / 진동 (모바일) / 화면 미세 셰이크

충돌 / 적중 판정

적-투사체 충돌은 원형 거리 판정으로 처리한다. Unity 물리 엔진을 사용하지 않으며, ECS Job 내에서 직접 거리 비교 (Burst 컴파일). 

// ECS 의사코드
foreach (Projectile p in projectileQuery)
  foreach (Enemy e in enemyQuery)
    if (distanceSquared(p.pos, e.pos) < (p.radius + e.radius)²)
      DealDamage(e, p.damage)
      if (--p.pierce <= 0) DestroyProjectile(p)
최적화 노트

Naive O(N×M)은 후반부 (적 500 × 투사체 50 = 25,000 비교)에서 부담. 실제 구현은 Spatial Hash Grid로 영역별 후보군만 비교. ECS 시스템 내부에서 처리하므로 메인 스레드 영향 없음. 자세한 내용은 06 ECS Hybrid 참고.

적이 타워에 도달했을 때

적이 타워와 충돌하면 타워에 데미지를 입히고 적이 소멸한다. 적 종류별 타워 데미지는 03 Enemy 참고.

  • 적이 타워에 닿는 즉시 타워 HP 감소 + 적 풀 반환
  • 타워 HP가 0이 되면 게임 종료
  • 적 충돌은 사격이 막지 못한 결과 → "방어선 뚫림"의 시각적 임팩트
